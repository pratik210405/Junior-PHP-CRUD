# Junior PHP Developer Internship - Week 1

## Project
Basic PHP CRUD Application using PHP, MySQL, PDO, HTML, CSS and JavaScript.

## Features
- Create user records
- Read/list user records
- Update user records
- Delete user records with confirmation
- Server-side validation
- PDO prepared statements
- Responsive interface
- Error/success messages

## Requirements
- XAMPP/WAMP/LAMP
- PHP 7.4+ (PHP 8+ recommended)
- MySQL

## Setup
1. Copy this folder into your XAMPP `htdocs` directory.
2. Start Apache and MySQL.
3. Open phpMyAdmin.
4. Import `database.sql`.
5. Check `config.php` and update the database username/password if required.
6. Open `http://localhost/junior_php_crud/`.

## GitHub
Create a new public repository and upload all project files except any local configuration containing passwords.

## Submission
Upload the ZIP of the project to the internship portal and paste your GitHub repository URL.
